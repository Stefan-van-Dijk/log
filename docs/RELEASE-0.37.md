# Log 0.37

Releasevoorbereiding voor de 0.37-lijn.

- Gedeelde kaarten kunnen uitvoerbare Log-payloads dragen.
- `log-code` configuraties kunnen worden toegepast.
- `log-task` gebruikt persistente `logCodeId`-identifiers voor bestaande subthema's.
- Voorbereiding voor samenwerken aan gedeelde kaarten met kaartgebonden schrijfrechten.
- Versienummer verhoogd naar 0.37.
